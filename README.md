# Income Tax Calculator
A simple Java program that calculates an example income tax amount based on the user's annual income and predefined tax slabs.

## Features
- Accepts annual income as user input
- Calculates tax using different income slabs
- Displays annual income and calculated tax

## Technologies Used
- Java
- Scanner class
- If-else statements
- Arithmetic operators

## How to Run
1. Download IncomeTaxCalculator.java.
2. Open a terminal in the folder containing the file.
3. Compile the program:
   javac IncomeTaxCalculator.java
   
4. Run the program:
   java IncomeTaxCalculator

## Purpose
This project was created to practise Java basics, user input, conditional statements, and arithmetic calculations.
